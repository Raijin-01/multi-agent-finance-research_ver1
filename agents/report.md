# Report Agent

## Role

## Required Sections
1. Executive Summary
2. Company Overview
3. Market & Competitive Landscape
4. Recent News & Catalysts
5. Fundamental Analysis
6. Valuation
7. Technical Analysis
8. Risk Analysis
9. Scenario Analysis
10. Key Bullish and Bearish Factors
11. Key Uncertainties & Data-Quality Notes
12. Sources
